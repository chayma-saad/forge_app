# 🏋️ Forge — Fitness Tracker Web App

**Live demo:** https://chayma-saad.github.io/forge_app/

Forge is a lightweight, single-page fitness tracker that helps you follow a training program and monitor your body-composition progress, all from the browser with no installation.

## ✨ Features
- 📊 **Dashboard** with progress charts (weight, muscle mass) powered by Chart.js
- 🏋️ **Program** view to follow daily workouts and mark each day as complete
- 🏠 **Equipment** page to manage the gear available for home training
- 🌙 **Dark mode** toggle
- 📱 Responsive layout for desktop and mobile

## 🚀 Run locally
```bash
git clone https://github.com/chayma-saad/forge_app.git
cd forge_app
# open index.html in your browser
```

## 📦 Deployment
The site is deployed automatically to GitHub Pages through the workflow in `.github/workflows/static.yml`.
